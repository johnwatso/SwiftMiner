Twitch Drops Not Progressing on Mac

If Twitch Drops progress stops in SwiftMiner, the cause is usually a duplicate viewing session, missing publisher account link, expired Twitch authorization, or an ineligible stream.

1. Stop duplicate viewing sessions

Twitch may only count one active watch session per account. Close Twitch on browsers, phones, TVs, or other devices using the same account that SwiftMiner is mining with.

2. Check publisher account links

Some campaigns require linking Twitch to a game publisher account before progress counts. Open the campaign in Twitch Drops Inventory and complete any Link Account or Connect step.

3. Reconnect expired Twitch sessions

If SwiftMiner shows Needs Auth, open Settings > Accounts and reconnect the affected account using the Twitch device activation flow.

4. Confirm the stream is eligible

Not every stream in a game category advertises the same active Drops campaign. SwiftMiner tries to choose eligible streams automatically, but campaign data can lag or change while streams are live.

The Drops tab shows eligibility and claim state per campaign, including drops that need an account link.

5. Restart the miner

Open the Miners view, stop the affected miner, wait a few seconds, and start it again. If this keeps happening, export diagnostic logs from the Help menu and attach them to a GitHub issue.

The Activity Log records each campaign scan and claim attempt, with the reason a cycle produced no candidates.
