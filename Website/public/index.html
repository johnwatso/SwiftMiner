Security built in.

Your Twitch password never passes through SwiftMiner. You sign in directly with Twitch, while the access tokens SwiftMiner needs stay protected on your Mac.

No password handling

SwiftMiner uses Twitch's secure device-code sign-in flow. The app never requests or stores your password, and authorization tokens are saved directly in the macOS Keychain.

Protected Web Dashboard

The optional Web Dashboard supports login protection before browser access is allowed.

Remote access is optional

Network and tunnel features are opt-in, so local use stays local unless you enable them.

Scoped external logins

When internet access is enabled, Twitch OAuth keeps people limited to their own miners.

Twitch Drops Miner Comparison: Native vs Python & Docker

While cross-platform Python apps are built for personal computers, running them on macOS often requires terminal workarounds and security overrides. Meanwhile, Docker setups are designed for headless servers; running them on a personal Mac introduces significant CPU, memory, and virtualization overhead.

Native Swift App

  • ✓ Instant Setup: Drag & drop to applications
  • ✓ Near-Zero RAM: Optimized compiled code
  • ✓ Secure: Gatekeeper signed & notarized
  • ✓ Auto-Updates: Native Sparkle updates
  • ✓ OS Integration: Leverages Apple's native software stack
Recommended for macOS

Python App

  • ✗ Signing: Not notarized, needs a Terminal workaround
  • ✗ Interface: Cross-platform UI, not native to macOS
  • ✗ Runtime: Packaged Python application
  • ✗ Updates: Manual re-download to upgrade

Docker Container

  • ✗ Setup: Requires Docker Desktop & compose files
  • ✗ Resources: Heavy always-on background daemon
  • ✗ No Interface: Container runs fully headless
  • ✗ Updates: Manual image pulls to upgrade
