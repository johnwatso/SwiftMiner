SwiftMiner 1.36.4

Version 1.36.4 · Build 2026073014

A more reliable and controllable web dashboard for operators and miners.

Reliable account identity

The web dashboard starts with the account information it needs.

  • Twitch profile pictures are resolved before the first dashboard page is served, avoiding the temporary Twitch-placeholder avatar.
  • The operator designation is synchronised to the web dashboard, so a linked Discord operator receives the complete fleet overview.

OAuth provider controls

Public sign-in can be adjusted without removing configured credentials.

  • Settings includes independent switches for Twitch and Discord OAuth sign-in.
  • Discord sign-in remains mediated by SwiftBot, retaining its server-membership verification.
