🧭 Version 1.38

  • 🩺 Each miner gets one operator panel: recovery status, live Twitch, campaign and drop-progress signals, and recent activity in a single Status card, quiet while the miner is healthy.
  • 📋 Up next and Campaign Queue are built from one resolved order, so the queue always agrees with the summary printed above it.
  • 📡 A miner with no eligible stream live says so on its own card, names the campaign it is waiting on, and confirms earning resumes automatically.
  • 🔗 A prioritised campaign awaiting a game-account link stays visible in the queue with its real scheduling status, marked so you know in-game delivery still needs the link.
  • 🔔 The game-account link reminder no longer goes quiet for the campaign a miner is currently mining — it stays in Needs attention and the badges whether the campaign is queued or being watched.
  • 🕐 Recent activity timestamps include AM/PM again, and a campaign can no longer appear twice in Campaign Queue.
  • ⚡ Active mining uses a gently pulsing bolt status symbol instead of looking like a playback button, respecting Reduce Motion.
  • 🧪 Debug builds can show a synthetic active campaign from the Developer menu for checking the mining UI safely.
  • ⭐ Drops adds All and Prioritised filters, with Prioritised following the selected miner’s effective priority list.
  • Updates SwiftMiner to version 1.38 build 2026082621.
