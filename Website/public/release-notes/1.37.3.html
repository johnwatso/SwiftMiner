SwiftMiner 1.37.3

Version 1.37.3 · Build 2026081709

Makes mining status clearer, diagnostics more responsive, and account controls safer.

🐝 Bug fixes

Fixes to status accuracy, diagnostics feedback, and recovery behaviour.

  • The Drops page names the exact campaign a waiting miner is checking, so a completed campaign for the same game cannot obscure why it is looking for streams.
  • Exporting diagnostics no longer appears unresponsive while SwiftMiner snapshots and redacts a large Activity Log.
  • Muted reminders no longer leave misleading Dock or sidebar badges.
  • Audit Activity Log entries are retained independently of routine activity, including after recovery from an interrupted database upgrade.
  • When Twitch rejects a saved session even after its refresh retry, mining pauses cleanly for reconnection instead of retrying the same rejected request every five minutes. The Activity Log identifies the HTTP 401 response.

📈 Clearer mining status

The app now explains what needs attention and what it is waiting for.

  • Every unmuted miner badge has a matching Needs attention panel with the recommended next step. Account-link warnings identify the game and open Twitch Drops directly; subscription blockers explain what is required.

📋 Responsive diagnostics

Large diagnostic exports now visibly stay at work.

  • Exporting diagnostics shows a preparation sheet while SwiftMiner prepares the report away from the main interface.
  • The preparation sheet cycles through the same coloured SF Symbols used by Activity Log categories.

👤 Account and game control

Each account can be managed without affecting the rest of the fleet.

  • The web dashboard lets a signed-in user remove their own mined account behind an explicit swiftminer typed confirmation. Removal stops mining, deletes the local account, and revokes its Twitch authorization; it never deletes the user’s Twitch account.
  • Each miner can exclude individual games from the web dashboard. An excluded game is neither watched nor claimed by that miner, while every other miner keeps its own list.
  • The native miner-detail header stays on Global unless the Web UI created a custom priority list; Reset to Global removes that override and restores the operator’s shared order.

🔒 Privacy and installation

Sign-in asks only for access SwiftMiner needs, and a downloaded app can put itself in the right place.

  • New Twitch device logins request no account scopes by default. Followed-channel access is requested only when Followed Streamer Prioritisation is enabled; chat, email, and subscription-list access are no longer requested.
  • When SwiftMiner is opened from Downloads, it offers to move itself into Applications and relaunch.
  • New installs now prompt for signed updates by default. Unattended download, install, and relaunch are available only after enabling Allow unattended updates in Settings.
