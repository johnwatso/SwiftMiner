SwiftMiner 1.36.8

Version 1.36.8 · Build 2026080214

Settings, web dashboard, and Twitch Drops reliability updates.

Twitch Drops reliability

Updates Twitch's persisted GraphQL queries for campaign discovery and drop inventory refreshes, and clearly flags future query or response changes that need a SwiftMiner update.

  • Safely coalesces duplicate progress records returned by Twitch instead of crashing during inventory refresh.

Dashboard identity

The dashboard now uses the linked Discord picture when Twitch has no custom profile image.

  • Replaces the generic Twitch silhouette with the linked Discord display picture when available.
  • Loads the Discord user cache before the dashboard begins serving account data.
  • Shows the same profile pictures in the macOS miner list, with the miner status symbol retained when no picture is available.
  • Adds a direct Overview button to each native miner operator header.

Cleaner settings

General now contains the artwork and miner-picture choices, removing the separate Appearance tab and controls that did not need user configuration.

  • Removes unused in-app tips.
  • Keeps Activity Log category icons and rich status presentation consistent, while continuing to respect macOS Reduce Motion.
  • Leaves IRL campaigns off by default.
  • Uses Discord's official mark for Discord sign-in.
  • Reports public dashboard and Discord sign-in availability from the live SwiftBot connection, rather than stale saved setup details.
  • Makes local dashboard credentials easy to set or change, without requiring the current password to be re-entered.
