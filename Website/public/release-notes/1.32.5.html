SwiftMiner 1.32.5

Version 1.32.5 · Build 2026072010

Clearer status for subscription-gated campaigns, plus updated Twitch mining transports, queries, and reconnect behavior.

🧘 Calmer Miner Status

Account-link warnings now appear only when linking is actually the reason a priority campaign cannot move forward.

  • Stops unrelated unlinked public campaigns from making a miner look account-blocked after its priority filters have already ruled those campaigns out.
  • Reserves the account-link blocked state for attemptable priority campaigns that genuinely belong to the miner's active priority list.
  • Falls back to no eligible campaigns when the only visible priority campaign is subscription-only and cannot be watched for progress.
  • Separates paid-subscription campaigns from the WebUI's Up Next list and labels their gated drops as requiring a Twitch subscription.
  • Hides the multi-miner global-priorities toggle when only one miner is configured and lets the native Miners workspace fill the available window width.

⛏️ Mining Reliability

SwiftMiner follows TwitchDropsMiner's latest proven transport and subscription behavior while keeping progress server-confirmed.

  • Updates the Twitch live-directory persisted query used to find eligible streams.
  • Sends watch heartbeats directly through Spade first, with Twitch GQL retained as an automatic fallback.
  • Restores desired PubSub topics after reconnects and splits subscription changes into bounded batches.
  • Refreshes the active campaign's complete Twitch inventory after verified progress so parallel drops stay in sync without inventing local progress.

🎯 Priority Mining Behavior

The mining rule stays the same: prioritised games can still be attempted even before the external game account is linked.

  • Keeps the miner focused on its effective priority list, including global priorities used by that account.
  • Avoids presenting account linking as a hard blocker when the miner is simply idle because Twitch has no eligible priority stream available.

🧪 Reliability Coverage

Regression tests cover the account-link cases that made this status feel too alarming.

  • Adds tests for unrelated unlinked campaigns, prioritised unlinked campaigns, and subscription-only priority campaigns.
  • Adds focused coverage for subscription-gated WebUI state, current Twitch query metadata, PubSub replay batching, and heartbeat fallback behavior.
  • Prepared as SwiftMiner 1.32.5, build 2026072010.
