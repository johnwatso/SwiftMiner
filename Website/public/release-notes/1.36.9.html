SwiftMiner 1.36.9

Version 1.36.9 · Build 2026080509

Reliable miner profile pictures and a cleaner miner list.

Real profile pictures

SwiftMiner now uses a real profile picture whenever Twitch or Discord provides one, consistently in the macOS app and web dashboard.

  • Automatically uses the miner's custom Twitch picture, then its linked Discord picture if needed.
  • Skips Twitch's generic 404-user image and Discord's stock embed avatars.
  • Falls back to SwiftMiner's status symbol only when neither service has a real picture.

Cleaner miner list

The miner sidebar stays readable when priorities grow.

  • Shows a compact priority count instead of truncating game names in every miner row.
