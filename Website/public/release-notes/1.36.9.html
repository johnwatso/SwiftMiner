SwiftMiner 1.36.9

Version 1.36.9 · Build 2026080517

Reliable miner profile pictures and a cleaner miner list.

Real profile pictures

SwiftMiner now uses a real profile picture whenever Twitch or Discord provides one, consistently in the macOS app and web dashboard.

  • Automatically uses the miner's custom Twitch picture, then its linked Discord picture if needed.
  • Skips Twitch's generic 404-user image and Discord's stock embed avatars.
  • Falls back to SwiftMiner's status symbol only when neither service has a real picture.

Cleaner miner list

The miner sidebar and header now keep their focus on live state and the most useful operational context.

  • Removes the priority summary from every miner row; priorities remain available in the selected miner's controls.
  • Moves the miner's priority source into the header metrics beside uptime, last poll, and health, using compact Global, Mixed, and Personal labels.
  • Removes the redundant Overview and visible actions buttons; right-click the miner header for its actions.

Calmer macOS surfaces

Operational UI now uses neutral system materials, reserving colour for meaningful state.

  • Removes the decorative blue and purple window, sidebar, and campaign-placeholder gradients.
  • Uses flat system surfaces for missing campaign artwork and a flat accent fill for fallback miner initials.
  • Keeps semantic colour for status symbols, progress, and actionable controls; missing-artwork symbols now reuse Overview's SF Symbol treatment.
  • Logs WebUI priority-mode changes, shows the reason for dashboard connection failures, and gives Activity Log symbols enough room to avoid clipping.
  • Shows subscription-only priority campaigns as Mining decisions with a credit-card symbol, while leaving non-priority campaigns out of the Activity Log.
