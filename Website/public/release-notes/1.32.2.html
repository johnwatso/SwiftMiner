SwiftMiner 1.32.2

Version 1.32.2 · Build 2026070113

A mining-reliability update that stops limited-time campaigns from crowding out games that actually have live streams.

Live-Aware Campaign Selection

Campaigns with no live stream can no longer starve or repeatedly interrupt a game that does.

  • Ranks candidate campaigns by live-stream availability first, so a soon-to-expire limited-time campaign with no live channel no longer out-ranks a game (such as Overwatch) that has streams ready to mine.
  • Stops the every-few-minutes churn where a working watch session was torn down for a higher-ranked campaign that had no stream to switch to, then immediately resumed — leaving the mineable game barely making progress.
  • Still grabs a restricted esports drop the moment it goes live: a switch now happens only when the higher-ranked campaign is verified to have a live, watch-mineable channel.

Drop Safety

Twitch's internal/test drop fixtures are ignored.

  • Skips exact-match internal/test-looking Twitch Drops fixtures so SwiftMiner does not watch or claim them, while campaigns that merely contain the word "test" stay mineable.

Stall Recovery

Supervisor restart recovery is paused while its logic is reworked.

  • Hides and disables supervisor stall recovery by default, avoiding unnecessary miner restarts from idle states until the restart logic is tightened.
  • Prepared as SwiftMiner 1.32.2, build 2026070113.
