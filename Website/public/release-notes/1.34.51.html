SwiftMiner 1.34.51

Version 1.34.51 · Build 2026072714

This hotfix restores prompt miner startup for multi-account installations while retaining 1.34.5's process-wide Twitch request coordination.

🚑 Miner Startup Restored

Dashboard hydration can no longer hold every miner in an idle-looking state after launch.

  • Miner workers start after essential account and callback setup instead of waiting for a complete account-state refresh.
  • Account-state hydration begins in the background after mining has had first use of the shared Twitch request budget.
  • Simultaneous mining and dashboard campaign refreshes for one account share a single in-flight operation instead of duplicating every campaign-detail request.

⛏️ Honest Miner Status

The interface now distinguishes operational startup from completed drop work.

  • Workers waiting to launch display Starting with connection context.
  • Workers that are not running display Stopped instead of Up to Date.
  • Active miners show the known drop duration immediately instead of a generic “checking progress with Twitch” message.
  • Miner progress shows verified watched minutes out of required minutes across every timed drop in the campaign, independent of channel or session.
  • Redesigns each miner as an operator detail view with identity and live health, a Now → Next → Then summary, a resolved campaign queue, compact subsystem checks and priority controls, with detailed recovery history kept secondary.
  • Refines the miner detail view with Tahoe-style grouped surfaces, roomier sentence-case sections, responsive campaign artwork and a cleaner source list.
  • Shows the linked Discord account avatar in the miner header when available, with a local initial fallback.
  • Lazily builds off-screen detail sections and resolves each source-row activity snapshot once per render for smoother navigation and scrolling.
  • Launch-time campaign and progress refreshes display Updating with a refresh symbol instead of prematurely reporting Up to Date.
  • Prioritised artwork stays visually stable when returning to Overview instead of replaying its placeholder crossfade.
  • Direct Twitch watch beacons now include the current stream category, client timestamp, live-state, and watched-minute fields required for drop progress to be credited.
  • Added regression coverage for startup status and concurrent cold campaign refreshes.
  • Updates SwiftMiner to version 1.34.51 build 2026072714.
