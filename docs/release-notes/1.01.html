SwiftMiner 1.01

Version 1.01

A first look at miner health on the dashboard, plus a smoother startup for multi-account setups and tidier onboarding wiring.

📊 Miner Health Overview

The dashboard now surfaces a quick read on how miners are doing.

  • Adds a dashboard health card so the state of the miners is visible at a glance.
  • Staggers multi-account miner startup so several accounts no longer launch all at once.

👋 Onboarding & Auth

The first-run experience is simpler while still remembering where you left off.

  • Simplifies onboarding and auth UI wiring.
  • Preserves the dismissed onboarding state so it does not reappear after setup.

🔧 Maintenance

Project versioning is bumped to match the new release.

  • Updates the Xcode project marketing version to 1.01.
