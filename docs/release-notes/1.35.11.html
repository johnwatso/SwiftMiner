Release SwiftMiner 1.35.11

A reliability release for the mining loop. Every account had quietly lost its
real-time drop connection, and idle miners were spending their whole Twitch
request budget re-asking questions they had just answered.

Real-time drop progress

- Stop treating an invented token deadline as proof a token is dead. Sessions
imported from cookies store no refresh token, and the web client reports no
expiry, so SwiftMiner fabricated a 30-day deadline. Once it passed, every
refresh failed instantly while the token was still serving hundreds of
successful GraphQL requests, taking PubSub offline for the whole fleet and
leaving mining on polling alone.
- Revalidate such tokens against Twitch and re-arm the local window from what
Twitch reports. A transport failure keeps the existing token rather than
taking a working account offline; only a 401 is treated as fatal.
- Load the access token and open the PubSub connection as separate steps. A
token failure used to skip both, and a rejected token was logged and
forgotten; it now surfaces as an account that needs reconnecting.

Idle request budget

- Share approved-channel liveness across every miner. Restricted esports
campaigns list dozens of approved channels, and each miner probed all of
them per selection cycle and again per idle tick: 641 probes and 22 minutes
of accumulated rate-limit backoff inside a three-minute window.
- Cache only misses, and only for less than one probe interval, so a channel
coming online is still found on the next tick. The cache can never be the
reason a campaign is missed; a test pins that relationship.
- Back off the followed-channel lookup after a failure instead of retrying it
every cycle, where each attempt forced another doomed token refresh.

Honest status

- Include the game the scheduler actually selected when evaluating per-game
state. Only prioritised games were considered, so a miner hunting streams
for a non-prioritised campaign reported "Drops complete".

Tests and versioning

- Pin the liveness cache window below the probe interval, and assert a live
channel is never cached.
- Cover a scheduled non-prioritised game producing its own state and not
reading as finished.
- Update SwiftMiner to version 1.35.11, build 2026072910, and add the 1.35.11
release notes page.
