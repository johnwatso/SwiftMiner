Fix Overview progress bars sweeping from zero on every appear

AnimatedLinearProgressView reset its displayed value to 0 in onAppear
and animated up to the real value every time it appeared. On the
Overview that meant the miner progress bars re-filled from empty each
time the page was shown or refreshed — which looked odd and made live
progress seem to only move on refresh (a refresh restarts miners and
re-mounts the cards, re-triggering the sweep), masking the small
incremental steps that were actually happening.

The bar now seeds its displayed value to the true progress at init, so
it renders where the miner actually is on the first frame, and animates
only genuine changes. Reduce Motion still applies instantly.

Ships as 1.34.2 (1.34.1 was released while this was in progress): new
1.34.2 notes, MARKETING_VERSION 1.34.2, build 2026072310 (bumped past
1.34.1's same-hour 2026072309 so Sparkle sees it as newer). Released
1.34.1 notes and the appcast are untouched.
