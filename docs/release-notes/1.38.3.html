SwiftMiner 1.38.3

Version 1.38.3 · Build 2026083108

A performance release. SwiftMiner stops repeating the same campaign, cache, and interface work on every refresh, keeps its image caches inside a fixed budget in memory and on disk, and reports what the event outbox is doing. Webhook retries now use the correct timing in every region, and the local dashboard turns away oversized or malformed requests before it reads them.

🐝 Fixes

Webhook retries keep their schedule wherever you are.

  • Reads the event outbox's stored timestamps with a fixed calendar rather than the one your region is set to. On a non-Gregorian regional calendar the timestamps failed to parse, so a webhook that needed retrying was retried immediately instead of after its backoff.

⚡ Less repeated work

Campaign refreshes stop redoing what they already did.

  • Keeps each account’s decoded campaign cache in memory after its first load and coalesces concurrent refreshes, instead of reading and decoding the same multi-megabyte file repeatedly.
  • Builds indexed campaign lookups across accounts and collects their cached snapshots concurrently, avoiding repeated full-list scans as account and campaign counts grow.
  • Builds both shared and per-account campaign views from the same refresh snapshot, removing a second collection and aggregation pass after every refresh.
  • Skips campaign and inventory cache rewrites when only refresh timestamps changed, while periodically renewing the persisted timestamp so offline cache freshness remains accurate.
  • Writes miner identities to the dashboard database only when identity data changes, rather than after every log or health update.

🖼 Bounded caches

Artwork and profile pictures can no longer grow without limit.

  • Bounds decoded campaign artwork, profile-picture, and sampled-tint memory; artwork and tint sampling now share downloads and reuse one image-processing context.
  • Caps each image cache folder on disk by size and file count, evicting the oldest files once either budget is passed.
  • Limits volatile miner telemetry presentation updates to once per second while still publishing state, health, task, and progress changes immediately; Dock badge refreshes are coalesced and unchanged badge values are ignored.
  • Halves decorative campaign-card animation updates and stops them for Reduce Motion as well as when SwiftMiner is inactive.

🔐 Local dashboard and diagnostics

Bounded requests, and an event outbox that says what it is doing.

  • Bounds local dashboard request headers and bodies, times out incomplete requests, and rejects malformed, duplicated, or unsupported body framing before authentication and routing.
  • Records event-outbox queue depth, the age of the oldest undelivered event, and webhook delivery timings, and includes them in exported diagnostics.
