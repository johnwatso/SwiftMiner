SwiftMiner 1.31

Draft release notes for work in progress

A work-in-progress update that keeps prioritised drops visible in more situations and noticeably trims SwiftMiner's CPU usage.

🎮 Drops & Campaigns

Prioritised and subscription games stay where you expect them.

  • Keeps prioritised games visible in Drops Active even when Twitch reports the active campaign as unlinked.
  • Preserves subscription-required reward treatment for same-game campaigns, including the credit-card badge and Sub label on paid-sub reward thumbnails.
  • Suppresses same-game Up Next entries that would otherwise duplicate an active subscription-required campaign.
  • Restores the Drops Active filter guard so unlinked, non-prioritised public campaigns do not clutter the active campaign list.

⚡ Performance

Lower CPU usage while mining and refreshing.

  • Lowers CPU usage by caching decoded game preferences instead of re-parsing the saved data on every screen update.
  • Cuts CPU spikes during campaign refreshes by reusing date formatters when parsing Twitch campaign dates rather than recreating them for every date.
  • Builds the prioritised campaign feed and each miner's activity card once per redraw instead of several times, reducing CPU while the Overview is on screen and during refreshes.
  • Pauses the animated campaign-card backgrounds when SwiftMiner is not the active app, so it no longer spends CPU animating in the background.

✨ Polish

  • Adds a SwiftMiner Website item to the app menu so swiftminer.app is easy to open from About SwiftMiner.
  • Adds a SwiftMiner Help item to the Help menu that opens the hosted guide at swiftminer.app/help.
  • Adds regression coverage for live unlinked campaign relevance, same-game subscription-required campaigns, and grouped Drops state.
