SwiftMiner 1.20

Version 1.20

A wider release that smartens up stream selection, polishes the Activity Log, adds login launch controls, and tightens drop claiming so completed rewards stay accurate.

📺 Stream Selection

Each miner picks its watching channel more deliberately.

  • Adds smarter stream selection, including optional stream spreading so multiple miners avoid piling onto the same verified live channel when enough alternatives are available.
  • Adds an option to prioritise followed and subscribed Twitch streamers, with subscriptions ranked ahead of follows during channel selection.
  • Adds a Watching Streamer panel to miner views so each account clearly shows the channel and campaign it is currently using.

📜 Activity Log

A cleaner log that is easier to scan.

  • Refreshes the Activity Log with clearer filters and optional category icons.
  • Adds new-row animation and tidied timestamp formatting.
  • Renames the section to Activity Log in navigation for consistency.

🚀 Launch at Login

SwiftMiner can now start with macOS, with clear feedback if it cannot.

  • Adds login launch controls including Start at login and Start minimised.
  • Adds approval and error messaging for macOS login item setup so it is clear when something needs your attention.

✅ Drop Claiming

Completed and claimed rewards stay in sync with Twitch.

  • Improves drop claiming by syncing Twitch inventory before and after claims so completed and claimed rewards stay accurate.

⛏️ Mining Status

Overview and miner status messaging is more accurate.

  • Cleans up Overview and miner status language by removing the old Up Next/debug queue surfaces.
  • Shows waiting states more accurately so a miner is not described as active when it is not.

🔄 Updates & Maintenance

Sets the stage for richer in-app release notes.

  • Updates the Sparkle appcast and release-note links so the in-app updater can show richer What's New content.
