SwiftMiner 1.38.1

Version 1.38.1 · Build 2026082818

SwiftMiner now keeps the profile-picture service each account chose, restores the interface artwork missing on macOS 14 Sonoma, and reliably reopens from Applications after moving itself out of Downloads.

💬 Discord pictures

A Discord choice now stays a Discord choice.

  • Accounts set to Discord keep Discord's generated account avatar instead of silently falling back to Twitch.
  • The Accounts badge and web dashboard resolve the selected picture service consistently.
  • Twitch-first accounts still ignore provider placeholders and retain their existing fallback behaviour.

🧭 macOS 14 interface

The full SwiftMiner interface remains legible on Sonoma.

  • Restores navigation, recovery, account-link, empty-state, and menu icons that used symbols only available on newer macOS releases.
  • Keeps the newer artwork on later macOS versions while selecting compatible fallbacks on macOS 14.

📦 Applications handoff

Moving SwiftMiner out of Downloads now completes cleanly.

  • Reopens the installed copy from Applications after the move instead of quitting without returning.
  • Uses a separate activated instance for the handoff, covered by regression tests.
