Reduce retained network sessions; prepare SwiftMiner 1.45.10

Reuse one WebSocket URLSession across PubSub connections so reconnects no
longer create a separate session for every socket. Cancel each socket
independently, and keep caller-provided sessions usable after cancellation.

Release app-owned Twitch API sessions when their clients are destroyed and
remove expired HLS playback credentials when caching replacement tokens.
Add coverage for both session ownership boundaries.

Prepare curated 1.45.10 release notes and timestamp build 2026112707.
A multi-day diagnostic report identified thousands of retained WebSocket
sessions and rising memory use. A reconnect stress test showed that sharing
a session reduces session count, but completed CFNetwork WebSocket tasks can
still remain retained. Further long-running monitoring is needed; this change
does not claim to eliminate the entire memory-growth issue.

Validation: Debug xcodebuild build and full SwiftMiner test suite; verified
built app version, Sparkle feed and public key, and generated release notes.
