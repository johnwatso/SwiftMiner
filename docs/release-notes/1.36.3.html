SwiftMiner 1.36.3

Version 1.36.3 · Build 2026073013

A clearer view of what each miner is doing, what has been completed, and which games should be mined next.

📡 Trustworthy Miner Status

Every surface now reflects the miner's actual state more consistently.

  • Miner cards, detail views, Discord projections, and the web dashboard now draw on the same resolved state, preventing contradictory messages such as a miner being both finished and still searching for streams.
  • Waiting, authentication, recovery, and stalled-mining states are described more clearly, with the right follow-up action when attention is needed.
  • Priority queues stay stable as global and personal rules change, and priority artwork is resolved and remembered for older game rules that did not yet have a Twitch image.

🎁 Completed Drops Stay Visible

Completion history no longer disappears just because a campaign leaves the current curated feed.

  • The native Completed filter, Discord projection, and web dashboard retain completed campaigns during their current window, including those whose final Twitch inventory response arrives without full campaign detail.
  • Cached drop and artwork data is preserved for ended campaign shells, so history remains useful instead of reverting to blank entries.
  • The web dashboard groups completed drops with a weekly total and presents Twitch identity and mining status without repeated or competing summaries.

🎮 Clearer Priorities

Every prioritised game stays visible without shrinking its artwork.

  • The Overview's Prioritised artwork now forms a responsive grid: it fills each row with full-size game cards and continues onto a second row when there are more games than fit.
  • The existing Edit button remains available for managing the prioritised list.

⚙ More Reliable Mining

Background work is less likely to drift, overlap, or obscure an active session.

  • Channel checks run on a fixed schedule, event delivery is processed in order, and refreshes no longer overlap a new watch session.
  • Idle CPU, network recovery, App Nap behavior, and system diagnostics have additional safeguards and instrumentation for more dependable long-running mining.
