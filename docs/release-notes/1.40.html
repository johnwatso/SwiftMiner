Prepare the 1.40 release build

Refreshes the build number to the time of the release prep and syncs the
visible build reference in the 1.40 notes, which preflight enforces.

Also fixes the release gate itself. preflight_release.sh located the built app
by globbing DerivedData and taking the last path alphabetically, which picks an
arbitrary directory rather than the one it just built: a stale 1.34.51 folder
from July sorted last, so the gate failed a correct 1.40 build. Worse, a stale
build whose version happened to match would have passed the gate while the real
one went unchecked. It now asks xcodebuild for BUILT_PRODUCTS_DIR.
