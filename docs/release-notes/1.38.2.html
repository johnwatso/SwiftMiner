Split MinerEngine into per-responsibility files

MinerEngine.swift was 2,324 lines, over a quarter of it the watch loop alone.
Move the watch loop, claiming, campaign warnings, the ordered event consumer
and maintenance task, callback setters, and the UI projections into extension
files, following the +ChannelSelection and +DropProgress pattern already in
this directory. The actor body drops to 904 lines and holds the stored state,
initialisation, and public lifecycle API.

Behaviour is unchanged: members are moved verbatim. The cost of splitting a
type across files in Swift is access level — members read across a file
boundary are widened from private to internal, and PendingFailoverTarget is no
longer private because a non-private property uses it. Stored properties that
an extension cannot declare stay in the actor body.
