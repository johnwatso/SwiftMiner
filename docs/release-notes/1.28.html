SwiftMiner 1.28

Version 1.28 · Build 2026061218

A web-dashboard and sign-in update for browser-based miner visibility, tighter route handling, and a calmer Twitch account login flow.

🌐 Web Dashboard

Miner visibility can now move into the browser when the dashboard is configured.

  • Adds an optional web dashboard for browser-based miner visibility.
  • Supports local operator sign-in and Twitch sign-in scoped to the user's own mined account.
  • Restores self-service Twitch linking for Discord web sessions with a device-code card, activation polling, and automatic dashboard refresh once the account is linked.
  • Adds actionable dashboard issue buttons plus an Up Next campaign browser with box art, end/start timing, and one-tap prioritising for linked miners.

🛡️ Route Safety

Public dashboard paths stay narrow and intentional.

  • Tightens public route matching so only intended dashboard paths bypass the Bot-key API gate.
  • Updates SwiftMiner to version 1.28 build 2026061218 while leaving ShipHook-owned appcasts untouched.

📺 Twitch Login

Adding a Twitch account now feels more like a native macOS approval flow.

  • Modernizes the Add Twitch Account login sheet with a cleaner two-step approval flow.
  • Improves code presentation, copy feedback, and waiting, success, and retry states.
