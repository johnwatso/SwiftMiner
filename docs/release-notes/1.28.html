SwiftMiner 1.28

Version 1.28 · Build 2026060911

A SwiftBot control-room release. Discord gets better priority buttons, miner-specific choices show up in the app, and account-link warnings are now helpful without acting like a tiny clipboard supervisor.

💬 SwiftBot Controls

Discord can now steer the right miner instead of shouting into the global priority list.

  • Adds Discord controls for miner-specific game priorities.
  • Adds full priority-list replacement from SwiftBot's edit-games modal.
  • Improves Discord status and preview messages with recent campaign context and more realistic debug samples.
  • Caches Discord avatars so the integrations UI feels quicker and less flickery.

⭐ Personal Priorities

The Miners tab now shows the games that belong to one miner, not everyone.

  • Shows personal miner priorities in the miner detail view.
  • Adds quick removal controls for miner-specific priorities.
  • Preserves per-miner priority ordering so app and Discord edits stay in sync.

🔗 Account-Link Warnings

Warnings stay visible, but prioritised games can still try to earn progress when Twitch allows it.

  • Lets prioritised unlinked games keep mining when Twitch exposes usable drops.
  • Only attempts unlinked campaigns when that game is prioritised for that specific miner.
  • Adds Discord controls to pause or ignore known account-link reminders without muting the rest of SwiftBot.
  • Removes noisy drop-claimed DMs so Discord focuses on decisions that actually need attention.

🖥️ Overview Polish

A few small repairs make the dashboard feel steadier during refreshes.

  • Adds a miner account button to the overview.
  • Restarts miners from overview refresh without clearing campaign artwork.
  • Slows the Looking for Streams animation so it breathes more like macOS Wi-Fi search.

🛡️ Update Guardrails

The update feed stays in ShipHook's lane, with the Sparkle public key protected.

  • Tightens project guardrails so future changes keep the Sparkle public update key intact.
  • Documents that ShipHook owns appcast version fields, preventing ordinary dev commits from confusing Sparkle updates.
