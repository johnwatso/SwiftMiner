- Resolve renamed/branded Twitch categories broadly: carry campaign game slugs, consult DirectoryGameRedirect, expand through category search, and fall back to derived slugs without per-game alias maps.

- Verify directory and per-stream game IDs before accepting live channels, so a bad slug match cannot switch the miner into an unrelated category.

- Preserve special-event/IRL bypass behavior for campaigns that can earn from ACL channels outside a strict game category.

- Keep internal/test-looking Twitch fixture drops out of mining/claiming while normal campaigns that include test in broader text remain eligible.

- Leave supervisor stall restart recovery hidden/disabled while restart handling is tightened to avoid noisy self-restarts from idle states.

- Bump 1.32.2 build metadata to 2026070116 and update public release notes.
