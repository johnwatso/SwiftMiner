Prepare SwiftMiner 1.33 release

Release summary since SwiftMiner 1.32.5:

- Platform compatibility: lower every app, library, tool, publisher, and test deployment target to macOS 14 while retaining native Apple Silicon and Intel support. Keep macOS 15 Mesh Gradient and macOS 26 Liquid Glass features availability-gated so Sonoma uses established visual fallbacks. Document the compatibility-first policy in the README and website: older macOS versions and Intel remain supported until required app features or Apple frameworks make a newer target necessary.

- Campaign and WebUI status: restrict account-link blocking to attemptable priority campaigns, treat subscription-only priority work as ineligible when progress cannot be earned, project subscription requirements through the dashboard API, remove fully gated campaigns from Up Next, and present a dedicated Subscription required state with Needs Sub labels. Preserve the existing behavior that prioritised games may be attempted before an external game account is linked.

- Mining reliability: update Twitch live-directory discovery metadata, use direct Spade watch heartbeats with automatic Twitch GQL fallback, separate desired PubSub subscriptions from per-socket state, restore topics deterministically in bounded batches after reconnects, retry failed restoration with backoff, and refresh the active campaign inventory from Twitch after verified progress so parallel drops remain synchronized.

- Single-miner experience: hide global-priority controls when only one miner is configured, expose miner-count projections consistently to the WebUI, and allow the native Miners workspace to use the full available width.

- Quality and repository maintenance: add regression coverage for account-link and subscription-gated states, dashboard projections, single-miner behavior, PubSub batching and replay, heartbeat fallback, current Twitch query metadata, and campaign-wide progress refreshes. Remove redundant Swift access modifiers and immutable-header warnings, align generated Xcode 26.6 project metadata with project.yml, and configure GitHub Linguist to focus repository language statistics on Swift.

- Website and release metadata: update download requirements and public copy for macOS 14, publish detailed SwiftMiner 1.33 release notes, restore the historical 1.32.5 notes to released build 2026070308, and set MARKETING_VERSION to 1.33 with timestamp build 2026072010 in both project.yml and the generated Xcode project. Leave the stable Sparkle appcast tied to the binary that is currently published.
