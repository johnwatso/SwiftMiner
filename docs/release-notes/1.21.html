SwiftMiner 1.21

Version 1.21 · Build 2026050412

A brighter quality-of-life release for smoother priorities, steadier artwork, calmer Twitch search, clearer account reminders, easier miner naming, and release notes you can open right inside SwiftMiner.

✨ Prioritised Games

Priority cards are easier to manage directly from the Overview.

  • Drag prioritised cards left or right to change their mining priority.
  • Improves drag feel with live card movement, smoother neighbour spacing, and spring settling.
  • Deduplicates prioritised cards by game id and normalised game name, fixing cases like repeated Call of Duty Warzone entries.
  • Adds context-menu actions for removing prioritised games and managing custom artwork.

🔎 Twitch Search

Finding games feels steadier while you type.

  • Debounces Twitch category searches so SwiftMiner waits briefly for typing to settle before sending the request.
  • Cancels older in-flight searches when a newer query is ready, keeping the suggestion list focused on the latest text.
  • Keeps the loading state visible during the debounce window so the dropdown does not flash a false "no results" message.

🎨 Artwork & Drops

Custom game artwork is more reliable and appears in more places.

  • Caches uploaded custom artwork in Application Support so it survives refreshes.
  • Matches artwork by game id or name so uploads apply more consistently.
  • Uses custom artwork across Drops campaign decks, grouped rows, campaign details, and fallback reward art.

👤 Miner Accounts

Account names and link problems are easier to handle from the Miners screen.

  • Adds right-click nickname editing from miner rows and miner activity cards.
  • Adds account-link reminders for prioritised games, with dismiss and remind-me actions per miner/game.
  • Aligns Dock and Miners sidebar badges so account-link attention only appears when there is a visible miner issue to review.
  • Shows a notification when a previously blocked prioritised game becomes linked and ready to mine.

✅ Drop History

Completed drops remain clearer when Twitch removes old campaign data.

  • Improves completed drop history when Twitch no longer exposes an expired campaign.
  • Uses cached completed campaign data only as a fallback while fresh Twitch data continues to win when available.
  • Fixes completed miner rows that could appear as waiting after both accounts had already claimed the campaign.

🔄 Updates & Maintenance

Update controls and cache maintenance are easier to manage.

  • Adds a What's New window in the app menu so the current release notes can be opened directly from SwiftMiner.
  • Derives release-note links from the configured stable or beta Sparkle feed, keeping in-app notes aligned with the selected update channel.
  • Adds an Anti-stall recovery setting, enabled by default, that restarts an individual miner when it appears stuck after a long progress stall or recoverable network error.
  • Adds Software Updates controls for choosing the stable or beta Sparkle feed.
  • Adds settings for update prompts and unattended update installs when macOS permits them.
  • Adds an Advanced settings action to clear cached drop history without removing accounts or app preferences.
  • Updates the stable Sparkle appcast and release-note links for SwiftMiner 1.21 build 2026050412.

⛏️ Mining Status

Miner status stays clearer while multiple accounts are running.

  • Summarises how many miners are currently mining instead of naming only the first active campaign.
  • Refreshes miner activity cards periodically so the displayed current and upcoming work stays fresh while the app remains open.
  • Removes the Claim All Drops app command now that ready rewards are claimed automatically.
  • Shows claiming rewards in activity cards instead of leaving completed drops labelled ready to claim.
  • Uses a green check for the menu bar status when all miners are running, with warning icons reserved for attention states.
