Release SwiftMiner 1.35.1

A follow-up to 1.35 that removes the multi-miner launch slowdown and stops
the miner status card reporting a paywall it was never waiting on.

Subscription-gated campaigns

- Stop presenting a subscription-gated campaign as a miner's current state.
Campaign and channel selection already excluded them, but the highest
priority one was substituted for the real status, so every idle miner
appeared parked on a paywall while it was actually looking for streams for
a different game.
- Treat a campaign whose only unclaimed drops need a paid subscription as
finished, so a prioritised game left with only those reads as up to date
rather than blocked.
- Stop a gated campaign suppressing the Up next row for another campaign in
the same game, which concealed work that could actually be mined.
- Keep the gated campaign visible as a mutable Pending reminder on the miner.

Requests and launch performance

- Fix the multi-miner launch slowdown that could leave accounts on Updating
for more than three minutes, by combining a bounded fleet request budget
with the existing five-request-per-second ceiling for each miner.
- Coalesce campaign refreshes at the Twitch client boundary so the mining
engine and dashboard share one campaign-detail fan-out.
- Coalesce cross-miner campaign-detail lookups once Twitch has confirmed each
account's link state, sharing campaign definitions while keeping progress,
claims, authentication and uncertain link state isolated per account.
- Prioritise followed streamers with one paginated followed-channel lookup
instead of one subscription request per candidate channel.

Queue and status honesty

- Explain Smart's deadline-first ordering, and report the miner's real recent
channel check instead of assuming no eligible live channel.
- Ignore unrelated unlinked campaigns while keeping an explicitly prioritised
game mineable before its external account is linked.
- Keep completed and unlinked campaigns out of prospective Up next and Then
positions, and only say Watching or Currently mining for a real session.
- Restore the Drops "Needs Setup" filter for live unlinked campaigns.

Tests and versioning

- Add coverage for startup refresh coalescing, per-miner ceilings inside the
fleet budget, account-state isolation, and followed-channel selection.
- Assert a subscription-gated priority game reads as up to date and no longer
suppresses a mineable campaign for the same game.
- Update SwiftMiner to version 1.35.1, build 2026072909, and add the 1.35.1
release notes page.
