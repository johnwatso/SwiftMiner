Add update error handling and Updates settings

Add error callback and UI for update failures, and bump build number.

- AppUpdater: introduce onError callback and implement updater(_:didAbortWithError:) to notify non-expected Sparkle abort errors (skips SUNoUpdate/SUInstallationCanceled codes 4001/2401/4003/2403).
- MinerApp: wire updater.onError to log a warning with a manual GitHub Releases download link when update checks fail.
- SettingsView: add an Updates tab (UpdatesSettingsView) showing current version/build, a manual GitHub Releases link, and update controls; refactor some bindings/helpers to reduce duplication.
- Bump build/version identifiers to 2026052921 across project.pbxproj, project.yml, docs/appcast.xml, and release notes HTML.

These changes improve visibility into update failures and provide a fallback path for users to download releases manually.
