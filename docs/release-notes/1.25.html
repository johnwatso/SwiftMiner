SwiftMiner 1.25

Version 1.25 · Build 2026052918

A major design refresh that introduces gorgeous Tahoe-style Drops cards with a native visual hierarchy, elegant remaining-time formatting, a new Ended campaign filter, and comprehensive automated release tooling.

✨ Tahoe Campaign Cards

A cohesive, clean layout that feels native and reduces visual noise.

  • Redesigns Drops campaign cards into an Apple-style cohesive horizontal band, keeping game artwork as the prominent card item and shrinking reward artwork to 72x72 to highlight the game hero.
  • Removes permanent text metadata below reward tiles, overlaying compact watch duration badges directly onto clean, static reward cards instead.
  • Animates reward names under the tiles dynamically on hover, maximizing visual efficiency and reducing card height.
  • Refines the aggregate status pill with soft, low-saturation capsule styling to keep visual focus on the rewards.

📊 Metadata & Status

Richer information with less visual clutter.

  • Uses clean, content-first SF Symbols (gift, calendar, and people) in the metadata row to keep visual elements quiet, structured, and native.
  • Introduces elegant remaining-time formatting, reporting time in days or a mixture of weeks and days (e.g. "1 week and 2 days left") instead of raw hours.
  • Compacts the miner details inspector popover with a denser layout and native macOS-style SF Symbols.
  • Ensures only eligible and actionable miners are represented on the card and popover surfaces.

🔍 Campaign Filters & Obtainability

Smarter filtering for completed, upcoming, and ended campaigns.

  • Introduces an Ended campaign status and filter (case ended / clock symbol) to clearly separate expired/finished campaigns from completed or claimed ones.
  • Refines Needs Setup and Blocked states so they only trigger if a campaign actually has obtainable rewards remaining, ignoring fully claimed or subscription-only drops with no watch progress.
  • Adds comprehensive unit test coverage for checking campaign reward obtainability.

🛠️ Integration & Release Tooling

Automated testing and simplified release operations.

  • Integrates automated testing for Discord API integration (DiscordAPIRoutesTests.swift) directly into the Xcode project target layout.
  • Introduces release scripts: bump_build_number.sh to keep settings and Sparkle manifests aligned, and preflight_release.sh to automate preflight checks and build validation.
  • Enhances Sparkle validation (validate_sparkle.sh) to fallback automatically to properties declared in project.yml for feed URLs and public keys.
