SwiftMiner 1.32.4

Version 1.32.4 · Build 2026070219

A follow-up performance and Drops filtering update that reduces duplicate Twitch work while keeping the selected miner view focused on that account's actual campaigns.

🎚️ Drops Miner Filtering

The Drops tab's miner picker now follows the selected account more closely.

  • Filters out unrelated idle campaigns from the merged feed when a single miner is selected.
  • Keeps the selected miner's current, prioritised, in-progress, claimed, setup-needed, blocked, and priority-ready campaigns visible.
  • Scopes grouped game-card account rows and miner counts to the selected miner so the card summary matches the filter.
  • Treats blocked account states as action-required/blocked instead of folding them into generic setup-needed state.

⚡ Mining Scan Efficiency

Multiple miners now share more short-lived Twitch lookup work.

  • Shares static campaign metadata, available-drops, live-directory, and game-slug lookups across miners with bounded caches.
  • Reuses sanitized campaign metadata without sharing account-specific progress or claim state between accounts.
  • Keeps negative subscription checks warm for longer while avoiding cache writes for authentication or transient request failures.
  • Clears campaign metadata caches after successful claims so fresh campaign shape is fetched when claim state may have changed.

📡 Channel Selection

Broad scans do less verification work when the best channel choices are already clear.

  • Limits channel verification depth adaptively for unrestricted campaigns with many live streams.
  • Preserves deeper verification for restricted campaigns, priority games, multiple candidates, and duplicate-stream avoidance.
  • Backs off repeated no-candidate scan cycles up to 15 minutes while still letting manual rescans interrupt the wait.
  • Prepared as SwiftMiner 1.32.4, build 2026070219.
