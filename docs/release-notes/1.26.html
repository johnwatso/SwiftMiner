SwiftMiner 1.26

Version 1.26 · Build 2026060111

A reliability release for clearer update failures and more accurate multi-miner Drops status.

↻ Update Handling

Update failures now surface clearly with a manual fallback path.

  • Adds an updater error callback and handles non-expected Sparkle abort errors.
  • Logs a warning with a manual GitHub Releases download link when update checks fail.
  • Adds an Updates settings surface showing the current version/build, update controls, and a manual releases link.

🎮 Drops Accuracy

Merged campaign status now stays account-specific.

  • Fixes merged Drops campaign account states so one claimed miner no longer makes every miner appear claimed.
  • Keeps completed campaign routing tied to each miner's own inventory-backed claim state.

🚀 Release Metadata

Version and update metadata are aligned for the 1.26 release.

  • Updates SwiftMiner's marketing version to 1.26.
  • Updates the stable Sparkle appcast and release-note metadata for SwiftMiner 1.26 build 2026060111.
