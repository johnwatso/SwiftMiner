Discord & SwiftBot Integration

Bring Twitch Drops updates to the place you already hang out. Learn how SwiftBot enables self-serve account setups, checks miner status via commands, and forwards drop notifications.

SwiftMiner was originally built for a small group of friends who play games together. SwiftBot is the Discord companion that connects the SwiftMiner app on your Mac to your Discord server. It removes background administration chores by letting friends link their own accounts and check statuses directly from Discord.

What SwiftBot can do

SwiftBot is designed strictly as a helper utility. It has limited permissions to protect your privacy.

SwiftBot can:

  • Send setup codes to link Twitch profiles.
  • Notify you when Drops are claimed.
  • Report current watch time and campaign info.
  • Alert you when Twitch sessions expire.
  • Securely expose the Web Dashboard online via Cloudflare Tunnels (or other relays) so friends can self-serve.

SwiftBot cannot:

  • Post public messages on your behalf.
  • Access your Discord passwords.
  • Read your server DMs or chat histories.
  • Access or store your Twitch passwords.

Connect Discord & Twitch

To register your account and link your Twitch profiles via Discord, follow these steps:

  1. Register your profile:

    In any Discord server where SwiftBot is installed (or by messaging the bot directly), send the /miner command. For example, type /miner action:status.

  2. Connect Discord to SwiftMiner:

    After your first command, SwiftBot will send you a direct message welcoming you and explaining how to authorize your account.

  3. Link Twitch account:

    Send /miner action:setup. SwiftBot will reply with an 8-character activation code.

  4. Authenticate on Twitch:

    Open twitch.tv/activate in your web browser. Make sure you are logged in to the Twitch profile you want to mine on, enter the activation code, and click Authorize.

  5. Confirmation:

    SwiftBot will send you a DM confirming the link. The SwiftMiner application will automatically start tracking campaigns for your Twitch account.

Twitch Token Renewal

Twitch authentication tokens expire occasionally. When this happens, SwiftBot will DM you a warning. Simply run the /miner action:setup command again to quickly renew the token.

Slash Commands

You can use these commands in a Discord server channels or in direct messages with the bot:

/miner
Displays a detailed dashboard card of your active miners and progress.
/miner action:setup
Generates a new Twitch device-code activation flow to link or renew a profile.
/miner action:status
Returns a quick, single-line text summary of what your miners are currently watching.

DMs & Notifications

SwiftBot only messages you when action is required or a reward is earned. It will not spam heartbeats or progress ticks.

Notification Description
Drop claimed Sent when a reward has been claimed on Twitch. Shows the item name and game.
Campaign complete Sent when all available rewards for a campaign have been unlocked.
Twitch connection expired Sent when a session needs renewal (Needs Auth) to prevent farming interruptions.
Link Twitch for game Sent when a publisher (e.g. EA or Ubisoft) requires external account connection to receive items.
Welcome back Sent when SwiftMiner reconnects after a network drop or crash.

Troubleshooting Discord

Not receiving Direct Messages from the bot

If commands work but SwiftBot does not send you DMs, check your Discord privacy settings:

  1. Right-click the server icon in your server sidebar.
  2. Choose Privacy Settings.
  3. Toggle Allow direct messages from server members to ON.

Activation code expired

Twitch activation codes are only valid for 10 minutes. If yours expires, simply request a new one by running /miner action:setup again.

Privacy Principles

  • Stored details: SwiftBot database only records your Discord ID, Twitch username, and connection status.
  • No Credentials Saved: Your Twitch password is never seen or handled by SwiftBot. Sign-in is handled directly on Twitch's servers.
  • Self-Service Unlinking: If you want to stop using SwiftBot, ask the server administrator running the SwiftMiner application to delete your Twitch profile from the Accounts list.
