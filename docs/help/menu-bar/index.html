Using Menu Bar Mode

Keep your workspace clean. Learn how to configure SwiftMiner to run quietly in the background as a macOS menu bar application while maintaining full access to controls.

SwiftMiner is designed to run efficiently in the background. If you prefer not to keep the app icon sitting in your macOS Dock, you can enable Menu Bar Mode. This lets the application live exclusively in the top right menu bar of your screen, letting you watch streams and claim rewards without visual clutter.

Enable Menu Bar Mode

To move SwiftMiner to the menu bar:

  1. Open SwiftMiner Settings (⌘,) and stay in the General tab.
  2. Locate the App Presence picker.
  3. Choose either:
    • Menu Bar Only: Hides the Dock icon completely. The app is only accessible via the menu bar icon. Closing the main window keeps miners running.
    • Dock + Menu Bar: Shows the icon in both the Dock and the menu bar.
  4. Additionally, ensure Run in background when closed is toggled to ON. This guarantees that clicking the red window-close button does not stop your miners.

Menu Bar Controls

When running in Menu Bar mode, clicking the SwiftMiner bird icon in the status bar opens a dropdown menu containing quick actions:

  • Miner Statuses: Lists each connected account and its active stream (e.g. @Ninja - 42%). Clicking an account opens the main window directly to that miner's details.
  • Recent Claims: Displays a list of recently claimed drops rewards.
  • Start / Stop All Miners: Quick control toggles to pause or resume farming across all accounts.
  • Refresh Progress (⌘R): Forces an immediate refresh of Twitch Drop campaign data.
  • Help Menu: Quick access to check for updates, export diagnostic logs, or open help documents.
  • Quit: Closes all active miner sessions and terminates the application.
