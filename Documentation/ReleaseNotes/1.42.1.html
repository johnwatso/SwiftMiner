SwiftMiner 1.42.1

Version 1.42.1 · Build 2026092520

SwiftMiner 1.42.1 fixes adding Twitch accounts, which stopped working after a change on Twitch’s side, along with updates for copies moved to Applications and several miner start-up glitches. Waiting miners also do less redundant work, and diagnostics now keep a full week of history.

🐝 Bug fixes

  • Adding a Twitch account works again. Since September 18, new accounts and Discord invitations failed with “invalid client”. Accounts you already added were not affected and do not need to sign in again.
  • Copies moved with the “Move to Applications” prompt can update again, instead of failing every update check with “SwiftMiner can’t be updated if it’s running from the location it was downloaded to”.
  • Opening SwiftMiner while it is already running no longer restarts active miners or wrongly shows them as blocked. Repeated start requests from SwiftBot or the web dashboard are now ignored too.
  • A campaign paused for making no progress now stays paused for its full 30 minutes, instead of being picked again straight away as a fallback for the same game.
  • Backing up settings and exporting diagnostics now use the standard macOS save dialog, which opens reliably.
  • The web dashboard now reopens as a single window and comes to the front, whether it was closed, minimised or behind another window.
  • Skipped Twitch test Drops are now logged once, not on every automatic claim check.

⚙️ Steadier mining

  • Newly added accounts sign in through Twitch’s TV app and search for campaigns across every game with live Drops streams, checking your priority games most thoroughly. Twitch only shows whether a game account is linked once a campaign has some progress, so these accounts may briefly watch a new game to find out.
  • A waiting miner only wakes up when an approved channel goes live with the campaign it is waiting for, not when that channel streams unrelated Drops.
  • Waiting miners keep their connection to Twitch channel updates between scans, rather than disconnecting and reconnecting each time.
  • Automatic reward checks run every two minutes, even when channel activity wakes the miner more often. Claiming manually still checks right away.

📋 Diagnostics

  • Diagnostic logs are now split into one file per day, and SwiftMiner keeps the last seven. An export includes the whole week.
  • Export Diagnostic Logs starts in the Desktop folder. A progress card stays on screen while a large report is gathered and redacted, and the finished file is shown in Finder.
  • Long sessions with several miners use less CPU to trim the Activity Log.

🎨 Interface

  • Claimed rewards take up less room on the Drops shelf. To see which miner earned a reward, use its info button or hover over the card.
  • A miner waiting for a campaign that only runs on approved channels shows a small Limited badge on its Overview card.
  • The web dashboard can show completed Drops for priority games or for all games, and each browser remembers its own choice.

📚 Help

  • The Help Center has been trimmed to a smaller set of up-to-date guides. Old article links redirect to the current page, so bookmarks still work.
  • A new About article covers SwiftMiner’s history, from the first automation scripts and a Windows VM setup through the first Mac prototype to the native rewrite, and credits the projects that helped along the way.
