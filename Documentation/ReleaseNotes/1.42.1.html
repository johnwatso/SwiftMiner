SwiftMiner 1.42.1

Version 1.42.1 · Build 2026092416

SwiftMiner 1.42.1 makes miners steadier while working and waiting, prevents reopening the app from disturbing active sessions, makes backups and diagnostics more reliable, and sharpens the dashboard and support experience.

🐝 Mining reliability

  • A live approved channel only wakes a waiting miner when the campaign it needs is active there. This avoids repeated campaign and inventory scans when a broadcaster stays live with unrelated Drops.
  • Waiting miners keep stable Twitch channel monitoring across ordinary rescans instead of repeatedly disconnecting and reconnecting the same subscriptions.
  • Automatic reward checks now follow their two-minute cadence even when channel events wake the miner more frequently. A manual claim still refreshes immediately.
  • Reopening SwiftMiner while it is already running no longer tries to start active miners again or incorrectly marks them as blocked. Duplicate start requests from SwiftBot and the web dashboard are safely ignored too.
  • A campaign paused after repeated no-progress stalls now stays out of same-game fallback choices for its 30-minute cooldown, so miners do not immediately return to the same unproductive campaign.

📋 Diagnostics

  • Diagnostics are written to a separate dated log file each day. SwiftMiner retains seven daily files and includes the complete seven-day timeline when you export diagnostic logs.
  • Export Diagnostic Logs now opens on the Desktop by default, making the finished report easier to find.
  • Settings backups and diagnostic reports now use reliable native file dialogs. A progress card remains visible while a large diagnostic report is collected and redacted, then the saved file is revealed in Finder.
  • Long-running, multi-miner sessions prune Activity Log history in batches, reducing CPU spent repeatedly sorting the same entries.
  • Internal Twitch test Drops are reported only once when skipped, keeping repeated automatic claim checks from filling the Activity Log with the same message.

🎨 Interface

  • Claimed rewards keep the Drops shelf compact. Miner ownership remains available from each reward card’s info button and hover details instead of appearing as a label beneath every reward.
  • When a miner waits for a campaign restricted to approved channels, its Overview card shows a small Limited badge so the narrower stream choice is easier to understand.
  • The web dashboard can show completed Drops for priority games or all games. The choice is remembered separately in each browser.
  • The dashboard now reopens as a single window and reliably comes forward whether it was closed, minimised, or behind another window.

📚 Help and project story

  • The Help Center now focuses on a shorter set of maintained guides. Older article links redirect to their current destinations, so existing bookmarks still lead to useful instructions.
  • A new About article tells SwiftMiner’s story from its first automation and Windows VM setup through the original Mac prototype and native rewrite, with clearer credit for the projects that helped shape it.
