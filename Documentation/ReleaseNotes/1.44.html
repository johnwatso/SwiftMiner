SwiftMiner 1.44

Version 1.44 · Released 2 October 2026

SwiftMiner 1.44 restores adding Twitch accounts after Twitch’s sign-in change, improves campaign discovery for additional accounts, and fixes updates for copies moved to Applications. It also makes mining and relaunching more reliable, explains when every available reward has been earned, and keeps a full week of diagnostics. These notes cover the changes since 1.42, the previous published release.

🔑 Twitch sign-in works again

  • New installations connect their first account through Twitch’s own website inside SwiftMiner. Password and two-factor prompts go directly to Twitch; SwiftMiner checks campaign and inventory access before saving the account as the Operator.
  • The Operator shares the full campaign catalogue with additional accounts and renews Twitch’s security check in the background. If renewal needs attention, the miner explains the problem and offers Reconnect Twitch.
  • Additional accounts, including friends joining through SwiftBot or the web dashboard, sign in through Twitch’s TV app. Each miner uses its own account for eligibility, inventory, progress and claims, and can search live channels when the Operator is unavailable.
  • Existing accounts keep their working sign-in. Reconnecting an account on Twitch’s retired Android sign-in preserves that session while Twitch still accepts it; removing an account now asks for confirmation and warns when its original sign-in cannot be restored.

🐝 More reliable campaign discovery and mining

  • TV-app accounts search games with live Drops streams, check priority games first, and mine priority games plus games Twitch already shows as linked to the account.
  • Campaign discovery uses Twitch’s correct live category URL and resolves streamer names to channel IDs before checking Drops. This fixes missed campaigns that could leave one miner showing “Up to Date” while another was already mining the same campaign.
  • A temporary channel-search failure preserves the last known campaign list and retries sooner. Changing priority games cancels outdated searches.
  • Campaigns paused for making no progress stay paused for the full 30 minutes. Waiting miners keep their channel-update connection and wake for the campaign they need, while automatic reward checks run every two minutes. Manual claims still check immediately.

🛠 Updates, relaunching and account display

  • Copies moved using “Move to Applications” can update again without the downloaded-location error.
  • Opening SwiftMiner while it is already running no longer restarts active miners or wrongly marks them as blocked. Repeated start requests from SwiftBot and the web dashboard are also ignored.
  • Profile pictures load for browser and TV-app accounts. Miner cards show the reward actually being earned and clearly say when all available rewards for priority games are complete.
  • Claimed rewards take up less room on the Drops shelf, and miners waiting for approved channels show a Limited badge. The web dashboard remembers each browser’s choice of completed Drops for priority games or all games and reopens as a single window.

📋 Clearer diagnostics and reliable exports

  • Diagnostic logs are kept in daily files for the last seven days, and exports include the full week. Exporting starts on the Desktop, shows progress while the report is gathered and redacted, and reveals the finished file in Finder.
  • Settings backups and diagnostic exports use the standard macOS save dialog, which opens reliably.
  • The Activity Log names fully earned campaigns and uses less CPU during long sessions. Repeated campaign-repair summaries appear at most hourly unless the count changes substantially, and skipped Twitch test Drops are logged once.

📚 Updated help

  • The Help Center has a smaller set of current guides, with redirects for old article links.
  • The About guide covers SwiftMiner’s history from its early automation scripts to the native Mac app and credits the projects that helped along the way.
