SwiftMiner 1.44

Version 1.44 · Build 2026100208

SwiftMiner 1.44 fixes campaign discovery for additional Twitch accounts signed in through Twitch’s TV app. Live Drops campaigns could be missed, leaving a miner showing “Up to Date” while another account was already mining the same campaign.

🐝 Additional accounts find live campaigns

  • Campaign discovery now reads Twitch’s canonical category URL, so priority games are searched in the correct live directory without unnecessary fallback searches.
  • When Twitch supplies a streamer name without a numeric channel ID, SwiftMiner resolves the ID before checking which Drops campaigns the stream is running. These streams can now contribute campaigns to discovery.

✅ Verified mining recovery

  • Verified that a second account discovers THE FINALS’ “FALL IS HERE” campaign, starts watching an eligible stream, and receives reward progress confirmed by Twitch.
  • Added regression coverage for Twitch’s current category response and streamer-name resolution; all 41 service tests pass.
