SwiftMiner 1.44.4

Version 1.44.4 · Build 2026100809 · Prepared 8 October 2026

SwiftMiner 1.44.4 moves off a stream that has stopped crediting drops in about six minutes instead of fifteen, holds less memory while the window is closed, and makes diagnostic exports show where memory is going. Engine 4.36.

🐝 Mining fixes

  • When a stream stays live but Twitch stops crediting watch time, SwiftMiner now switches to another channel after about six minutes instead of fifteen. It acts only when Twitch itself reports the same progress on six checks in a row and no other source has credited anything.
  • Drop names no longer carry the stray tab characters Twitch sometimes sends, which showed up in the Activity Log and notifications.

⚡ Less Twitch traffic

  • For campaigns that only count on a short list of approved channels, SwiftMiner now checks those channels directly instead of downloading the game's whole live directory every few minutes and discarding it.

🧠 Lighter in the background

  • Campaign artwork and profile pictures held in memory are now capped far lower, and are released when you close the window. They are still cached on disk, so reopening the window stays quick.

🩺 Clearer diagnostics

  • Diagnostic exports now include an hourly memory timeline, showing whether the window was open and how much of the total is app data. A climb can then be traced to the window, a cache, or steady growth.
  • The Activity Log no longer repeats "No claimable drops found" or "Higher-ranked campaign has no live channel" every few minutes. Each is logged once until something changes.
  • The earning ledger explains why rates above 60 minutes per hour are normal: several drops in a campaign progress at the same time.
