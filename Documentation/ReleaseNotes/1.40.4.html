SwiftMiner 1.40.4

Version 1.40.4 · Build 2026090311

Prioritised and excluded games now share one Game Rules sheet, Mining settings opens on a Game Priority summary, and the legacy fallback streamer steps out of the way until it is actually needed.

🎯 One Place for Game Rules

  • Prioritised and excluded games are now managed in a single Game Rules sheet. The separate Prioritised Games and Excluded Games sheets offered the same controls twice and let a game be moved between the lists anyway.
  • Searching adds a game directly as prioritised or excluded, so there is no longer a list to choose before looking a game up.
  • Every game carries a rule of Prioritised or Excluded. Changing that rule moves the game into the matching section and leaves its position in the priority order intact.
  • Both sections collapse, so a long priority list no longer pushes exclusions below the visible area.
  • Rows are quieter: artwork, name and current rule lead, with reordering and removal kept secondary to them.

⭐ Game Priority at a Glance

  • Mining settings now opens on a Game Priority summary showing how many games are prioritised and how many are excluded, with one Manage Game Rules entry point beneath it.

🧹 Fallback Streamers Out of the Way

  • The fallback streamer is a legacy feature and no longer occupies a row on every prioritised game. A game mentions its fallback only when one is actually configured.
  • The field now sits behind each game's own disclosure, with a single action beside it: Set while a new login is being entered, Clear once one is saved.
  • Changing a prioritised game to Excluded hides its fallback without discarding it. Switching the game back to Prioritised restores what was configured.
