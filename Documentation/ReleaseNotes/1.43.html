SwiftMiner 1.43

Version 1.43 · Build 2026092911

SwiftMiner 1.43 lets you add Twitch accounts again after Twitch shut down the sign-in SwiftMiner relied on. Your first account now signs in on Twitch’s own website inside SwiftMiner and supplies the full Drops campaign list; later accounts sign in through Twitch’s TV app. It also fixes updates for copies moved to Applications and several start-up glitches, makes waiting miners do less redundant work, and keeps a full week of diagnostics.

🐝 Bug fixes

  • Adding a Twitch account works again. Since September 18, new accounts and Discord invitations failed with “invalid client”. Accounts you already added were not affected and do not need to sign in again.
  • Copies moved with the “Move to Applications” prompt can update again, instead of failing every update check with “SwiftMiner can’t be updated if it’s running from the location it was downloaded to”.
  • Opening SwiftMiner while it is already running no longer restarts active miners or wrongly shows them as blocked. Repeated start requests from SwiftBot or the web dashboard are now ignored too.
  • A campaign paused for making no progress now stays paused for its full 30 minutes, instead of being picked again straight away as a fallback for the same game.
  • Profile pictures now load for every account, including those signed in through the browser or Twitch’s TV app. Pictures are read from Twitch’s public profile data, so they no longer depend on each account’s sign-in.
  • Backing up settings and exporting diagnostics now use the standard macOS save dialog, which opens reliably.
  • The web dashboard now reopens as a single window and comes to the front, whether it was closed, minimised or behind another window.
  • Skipped Twitch test Drops are now logged once, not on every automatic claim check.

🔑 Signing in after Twitch’s change

  • A fresh installation connects its first Twitch account through Twitch’s own website, inside a browser that belongs to SwiftMiner. Your password and two-factor prompts go straight to Twitch, and SwiftMiner checks the complete campaign dashboard and inventory before saving the account as the Operator.
  • SwiftMiner keeps the Operator’s Twitch security check renewed in the background. If Twitch rejects it, SwiftMiner renews it straight away and the miner explains what is happening, with a Reconnect Twitch button if it doesn’t clear by itself.
  • The Operator shares the full campaign list with accounts added after it. Every miner still uses its own Twitch session for channel eligibility, inventory, progress and claims, and searches live channels itself when the Operator is unavailable.
  • Accounts added after the first, including friends joining through the web dashboard or SwiftBot, sign in through Twitch’s TV app. They search for campaigns across every game with live Drops streams, checking your priority games most thoroughly, and mine your priority games plus any game Twitch already shows as linked to the account.
  • Existing accounts keep their original Twitch sign-in exactly as it is. Removing one now asks you to confirm first, with a stronger warning for accounts on Twitch’s retired Android sign-in: once removed, they can only come back with the more limited TV-app sign-in.
  • New TV-app sign-ins use one consistent Twitch identity from the activation screen onward, and a failed Keychain save cannot disturb a miner’s working token.

⚙️ Steadier mining

  • A temporary failure while checking live Drops channels keeps the last known campaign list and retries sooner, instead of making campaigns disappear. Changing priority games also cancels any older search still running in the background.
  • A miner’s card shows the drop it is actually earning, not a subscription-only reward that some campaigns list first.
  • A waiting miner only wakes up when an approved channel goes live with the campaign it is waiting for, not when that channel streams unrelated Drops.
  • Waiting miners keep their connection to Twitch channel updates between scans, rather than disconnecting and reconnecting each time.
  • Automatic reward checks run every two minutes, even when channel activity wakes the miner more often. Claiming manually still checks right away.

📋 Diagnostics

  • Diagnostic logs are now split into one file per day, and SwiftMiner keeps the last seven. An export includes the whole week.
  • Export Diagnostic Logs starts in the Desktop folder. A progress card stays on screen while a large report is gathered and redacted, and the finished file is shown in Finder.
  • The Activity Log names campaigns you have already earned in full, so a miner with nothing left to mine no longer looks like it is failing.
  • Long sessions with several miners use less CPU to trim the Activity Log.

🎨 Interface

  • Claimed rewards take up less room on the Drops shelf. To see which miner earned a reward, use its info button or hover over the card.
  • A miner waiting for a campaign that only runs on approved channels shows a small Limited badge on its Overview card.
  • The web dashboard can show completed Drops for priority games or for all games, and each browser remembers its own choice.

📚 Help

  • The Help Center has been trimmed to a smaller set of up-to-date guides. Old article links redirect to the current page, so bookmarks still work.
  • A new About article covers SwiftMiner’s history, from the first automation scripts and a Windows VM setup through the first Mac prototype to the native rewrite, and credits the projects that helped along the way.
