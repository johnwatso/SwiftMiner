SwiftMiner 1.40.1

Version 1.40.1 · Build 2026090212

This hotfix makes Discord profile pictures reliable when SwiftMiner and SwiftBot start together.

🐝 Fixes

  • Discord profile pictures now recover automatically if SwiftMiner checks SwiftBot before its user directory is ready, instead of remaining on the Twitch fallback for the rest of the session.
  • SwiftBot user-directory failures now appear in diagnostics, making future connection problems easier to identify.
