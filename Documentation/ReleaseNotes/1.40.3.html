SwiftMiner 1.40.3

Version 1.40.3 · Build 2026090310

The complete SwiftMiner 1.40 series: Discord now belongs to each miner, action messages lead to the right place, profile pictures recover reliably, and downloaded updates install cleanly.

🔗 Discord Belongs to Each Miner

  • The separate Discord sidebar has been replaced by a Discord section on each miner, keeping linking, account health, message history, resending, and welcome messages with the account they affect.
  • Collapsed sections show the linked account, current health, and message count; expanding one reveals recent messages and all account controls.
  • Not linked, unavailable, missing from SwiftBot, and failed delivery are now distinct states instead of variations of the same generic warning.
  • Pending items say when their own reminder was delivered and when automatic reminders are disabled.

👤 Dependable Profile Pictures

  • Picture-source changes apply immediately in Settings, Miners, and the web dashboard, while temporary network failures no longer erase a working Twitch picture.
  • Discord pictures recover automatically when SwiftMiner and SwiftBot start together or when SwiftBot experiences a short-lived directory or connection failure.
  • Linked accounts receive their real Discord picture without waiting for that member to trigger a new Discord event.
  • Discord's generated placeholder is no longer treated as a selected picture; SwiftMiner uses the account's Twitch picture until the real Discord avatar is available.

👉 Clearer Actions and Campaign State

  • Discord messages that require action now open the exact miner, campaign, account connection, or completed-drops page that resolves the problem.
  • Account-link reminders remain visible consistently in Needs Attention, Pending, and the sidebar count.
  • Claimed rewards waiting for a game-account link are described as undeliverable, rather than incorrectly saying the drops still need to be earned.
  • Subscription requirements, missing account links, and other known causes are stated directly, with a new guide for paid-subscription Drops.
  • Mining Settings now provides separate entry points for managing prioritised and excluded games.
  • Duplicate campaigns occasionally returned by Twitch are safely consolidated instead of crashing SwiftMiner while campaign status is calculated.

📊 Diagnostics That Are Ready When Needed

  • SwiftMiner now keeps lightweight CPU and memory measurements automatically, alongside the existing seven-day earning ledger, and includes both in diagnostic reports without requiring advance setup.
  • Performance reports distinguish the initial two-minute startup workload from steady-state mining, making cold-launch request bursts easier to interpret.
  • Followed-streamer prioritisation can recover after an account receives a new access token instead of remaining unavailable until SwiftMiner is relaunched.
  • Followed-streamer prioritisation is now labelled accurately; SwiftMiner does not claim to detect paid channel subscriptions.
  • The obsolete debug link-requirement bypass has been removed now that missing game-account links are handled as delivery warnings during normal mining.
  • Legacy cache-clearing and full-settings reset controls have been removed from Advanced Settings.

📦 Installation Fixes

  • A downloaded copy now locates the correct original app when macOS launches it through App Translocation, even if an older SwiftMiner is already installed.
  • Move to Applications safely replaces an existing copy and relaunches the newly installed app.
  • Unsigned development builds keep their integration secrets separate from release credentials, avoiding repeated Keychain prompts during launch.
