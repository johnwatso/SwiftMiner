SwiftMiner 1.44.2

Version 1.44.2 · Build 2026100513 · Prepared 5 October 2026

SwiftMiner 1.44.2 makes approved-channel mining checks more efficient and helps waiting miners recognise when an eligible broadcast is ready. Engine 4.33 also adds clearer diagnostics for streams excluded by campaign restrictions.

⛏ More efficient mining checks

  • Approved-channel campaigns now spend their bounded stream checks on approved broadcasters, keeping unrelated streams from taking those slots.
  • Channel selection avoids repeating live-state checks for streams already verified in the same scan. Waiting miners only restart a full scan when an active campaign is allowed on that broadcaster.
  • Activity logs now explain when channel restrictions leave no directory streams to verify, making waiting periods easier to diagnose.
