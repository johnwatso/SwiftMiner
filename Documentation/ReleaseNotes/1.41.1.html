SwiftMiner 1.41.1

Version 1.41.1 · Build 2026091609

SwiftMiner 1.41.1 spreads miners across streams properly, makes claiming faster, quiets the Activity Log, and adds a beta feature that can recover from Twitch query changes without waiting for an update.

🐝 Bug fixes

  • Finished campaigns no longer reappear as unmined when Twitch returns an incomplete inventory.
  • Miners choosing a channel at the same moment no longer all land on the same stream.
  • Claiming a drop is a few seconds faster — a follow-up Twitch call that always failed has been removed.
  • Campaign discovery works again after Twitch replaced its Drops dashboard query, and temporary Twitch timeouts are retried instead of stopping mining.
  • A miner is no longer flagged “Watching — Not Earning” the moment it starts watching after a quiet spell.
  • SwiftMiner no longer replaces its SwiftBot pairing secret when the Keychain can’t be read, which silently disconnected SwiftBot until you paired again.
  • The Overview health card shows how long your miners have been running normally again, instead of being held back by miners from earlier launches.
  • Inviting a friend through SwiftBot no longer lists bots and webhooks.
  • The Overview toolbar no longer shows a blank white strip in the Standard appearance.

🎨 Polish

  • Waiting miners now name the game they are waiting for, and the state reads “Waiting for an eligible live stream” everywhere.
  • Game Rules shows each game as its own compact card.
  • The miner’s Discord session now uses Discord’s official mark.
  • The Activity Log is much quieter: campaign decisions, viewer counts and “Already up to date” are logged far less often, and Twitch error pages are condensed to one line.
  • Diagnostic exports note when followed-streamer prioritisation is switched on but not working.

🧰 Automatic Twitch compatibility (beta)

  • When Twitch retires a query SwiftMiner depends on, SwiftMiner can find the replacement through its Safari extension and adopt it once verified — no app update needed. It checks at most every half hour and can be switched off.
  • Claiming a drop keeps working even if Twitch retires its query.
  • Advanced Settings shows a simple status board for each Twitch query in place of manual hash overrides.
  • The extension only ever passes an operation name and hash to SwiftMiner — never cookies, tokens or responses.
