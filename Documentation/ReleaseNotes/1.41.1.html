SwiftMiner 1.41.1

Version 1.41.1 · Build 2026091020

A miner waiting for a stream now says which game it is waiting on, the way a mining miner has always named the game it is watching. Inviting a friend through SwiftBot no longer offers the server’s bots as people to invite.

🐝 Bug fixes

  • A miner waiting for a stream now names the game it is waiting for. A miner that is watching leads its card with the game, and so do the claiming and stream-override cards — but the waiting card led with its state and left the game to a single line of detail, which a compact card on Overview cuts short. Waiting is the state a fleet spends most of its time in, and it was the one card that never said what it was waiting for. It now names the game where the watching card does, with the campaign beneath it and the game’s artwork alongside, while the antenna symbol and the absent progress bar go on saying that nothing is being earned yet. The miner’s detail page, the sidebar and the status label name the game too.
  • The wording of that state is now the same everywhere it appears: “Waiting for an eligible live stream”, in place of “No eligible stream live” on the card and “Waiting — No live stream” in the status label.
  • Inviting a friend through SwiftBot no longer lists the server’s bots and webhooks as people you could invite. A recipient without a bot flag is still treated as a person, so a server whose member list predates the flag is unaffected.
